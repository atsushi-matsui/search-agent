# アーキテクチャ

## 技術スタック

| コンポーネント | 技術 |
|--------------|------|
| バックエンド | FastAPI (Python) |
| フロントエンド | React 18 + TypeScript + Vite + Tailwind CSS |
| LLM | Claude (Vertex AI経由) |
| 検索エンジン | Elasticsearch 8.16.0 |
| キャッシュ/永続化 | Redis 7.4.1 |
| コンテナ | Docker Compose |

## ファイル構成

```
search-agent/
├── backend/
│   ├── app/
│   │   ├── agents/           # 各種エージェント
│   │   │   ├── base.py                    # 基底クラス
│   │   │   ├── conversation_analyzer.py   # 会話意図分析（LLM）
│   │   │   ├── query_understanding.py     # クエリ構造化（LLM）
│   │   │   ├── user_preference.py         # 嗜好取得（Redis、LLMなし）
│   │   │   ├── query_to_es.py             # DSL生成（LLM+ルール）
│   │   │   ├── retrieval.py               # ES検索（ルール）
│   │   │   ├── rerank.py                  # 再ランキング（LLM+ルール）
│   │   │   ├── answer.py                  # 回答生成（LLM）
│   │   │   ├── preference_updater.py      # 嗜好更新（LLM）
│   │   │   └── orchestrator.py            # オーケストレーター
│   │   ├── api/              # APIエンドポイント
│   │   ├── core/             # Elasticsearch, LLM, Redisクライアント, プロンプトローダー(prompt.py)
│   │   ├── models/           # Pydanticモデル
│   │   └── prompts/          # システムプロンプト（{エージェント名}/v{N}.md）
│   ├── scripts/
│   │   └── init_movies_index.py
│   └── requirements.txt
├── frontend/                 # React フロントエンド
├── docs/                     # ドキュメント
│   ├── ARCHITECTURE.md       # 本ファイル
│   ├── SPECIFICATION.md      # エージェント仕様
│   ├── presentation.md/.pdf  # 紹介スライド（Marp）
│   └── flow-diagram.*        # 処理フロー図
├── Makefile                  # 起動・データ投入などのショートカット
└── docker-compose.yml
```
