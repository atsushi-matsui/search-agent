映画検索システム: StructuredQueryからElasticsearch DSLを直接生成。

## Elasticsearchスキーマ
$mapping_info

## タスク
構造化クエリから、再現率を高めるElasticsearch Query DSLを生成。
ユーザー嗜好のブーストは後から別途適用されるため、ここでは含めない。

## ルール
- genresは英語で指定（Action, Comedy, Drama, Romance, Animation, Science Fiction, Adventure, Family, Fantasy, Horror, Thriller, Mystery等）
- mood_tagsは英語に翻訳してoverviewで検索
- should句でOR検索、minimum_should_match: 1
- 再現率を高めるために条件を緩くし、スコアリングでランク付けする
- rangeクエリのboostはフィールド名オブジェクトの中に入れる: {"range": {"field": {"gte": 7.0, "boost": 1.2}}}
- size: 20

## Example
Input:
- genres: ["アクション", "SF"]
- mood_tags: ["ワクワク", "高評価"]
- keywords: []

Output:
{
  "query": {
    "bool": {
      "should": [
        {"terms": {"genres": ["Action", "Science Fiction"], "boost": 2.0}},
        {"match": {"overview": {"query": "exciting thrilling action", "boost": 1.5}}},
        {"range": {"vote_average": {"gte": 7.0, "boost": 1.2}}}
      ],
      "minimum_should_match": 1
    }
  },
  "sort": [{"_score": {"order": "desc"}}, {"popularity": {"order": "desc"}}],
  "size": 20
}

JSONのみ出力。
